# 🚀 안드로이드 우주 슈팅 게임

Kotlin으로 만든 안드로이드용 세로 화면 슈팅 게임입니다.
위에서 내려오는 적 우주선을 총알로 맞혀 점수를 올리고, 적과 부딪히면 게임이 끝납니다.

이미지 파일 없이 **우주선, 적, 총알, 폭발 효과를 전부 코드로 직접 그렸고**,
효과음도 음원 파일 없이 **코드로 소리를 만들어서** 재생합니다. (배경음악만 MP3 파일 사용)

- 개발 기간: 2026년 5월 ~ 6월
- 개발 형태: 학교 과제 (개인 프로젝트)
- 언어: Kotlin
- 개발 도구: Android Studio (에뮬레이터로 테스트)

1. 안드로이드 폰에서 위 링크를 눌러 APK 파일을 받습니다.
2. 다운로드한 파일을 엽니다.
3. "출처를 알 수 없는 앱" 경고가 뜨면 **설정 → 이 출처 허용**을 켜고 돌아와 **설치**를 누릅니다.
4. 설치가 끝나면 **game** 앱을 실행합니다.

> Play 스토어 앱이 아니라서 3번 허용 과정이 한 번 필요합니다. 안드로이드 7.0 이상에서 실행됩니다.

## 🎮 게임 방법

화면 아래에 버튼 3개가 있습니다.

| 버튼 | 하는 일 |
|------|---------|
| ◀ | 내 우주선을 왼쪽으로 30픽셀 이동 |
| **FIRE** (빨간 버튼) | 총알 1발 발사 / 게임 오버 상태에서는 **다시 시작** |
| ▶ | 내 우주선을 오른쪽으로 30픽셀 이동 |

- 적은 화면 위에서 **1.5초마다 1대씩** 내려옵니다.
- 적을 맞혀서 체력을 0으로 만들면 격추되고 점수를 얻습니다.
- 적 우주선과 내 우주선이 **부딪히면 게임 오버**입니다.
- 점수가 오를수록 적이 **점점 빨리** 내려오고, **더 강한 적**이 섞여 나옵니다.
- 우주선은 화면 밖으로 나가지 않도록 양쪽 끝에서 멈춥니다.

## ✨ 주요 기능

### 1. 탄약 / 재장전 시스템
- 총알은 **최대 50발**까지 쏠 수 있습니다.
- 50발을 다 쓰면 **자동으로 재장전**이 시작되고, **3초** 동안은 쏠 수 없습니다.
- 재장전이 끝나면 "띵-띵" 하는 완료음이 한 번 울리고 다시 50발이 채워집니다.
- 화면 오른쪽 위에 남은 탄약이 숫자(`45 / 50`)와 막대로 표시됩니다.
  - 절반 넘게 남음 → 파란색 막대, 흰 글씨
  - 20% ~ 50% 남음 → 노란색
  - 20% 이하 → 빨간색
  - 막대에는 10발마다 눈금선이 있어서 남은 양을 한눈에 볼 수 있습니다.
- 재장전 중에는 `RELOADING...` 글자가 깜빡이고, 노란 막대가 차오르면서 남은 시간(예: `1.8s`)을 보여줍니다.

### 2. 체력이 있는 적 3종류
- 적마다 체력(HP)과 점수가 다릅니다. → [적 종류](#-적-종류) 참고
- 체력이 2 이상인 적은 머리 위에 **체력 막대와 숫자(예: `2/3`)** 가 나옵니다.
- 맞을 때마다 적이 **하얗게 번쩍**이며 맞았다는 걸 알려줍니다.

### 3. 점수에 따라 어려워지는 난이도
- 적이 내려오는 속도 = `8 + (점수 ÷ 60)` 픽셀/프레임
  - 예: 0점일 때 8, 120점일 때 10, 300점일 때 13
- 나오는 적의 종류도 점수에 따라 늘어납니다.
  - 0 ~ 49점: 마름모형만 등장
  - 50 ~ 99점: 마름모형 + 육각형
  - 100점 이상: 세 종류 모두 등장

### 4. 폭발 / 피격 효과
- **격추**하면 작은 불꽃 조각 22개가 사방으로 튀고, 중력 때문에 아래로 떨어지면서 점점 작아지고 흐려집니다.
- **맞기만 하고 격추는 안 됐을 때**는 조각 6개만 짧게 튑니다. (격추와 구분되도록)
- 불꽃 색은 적 종류마다 다릅니다. (빨강/노랑, 주황, 보라 계열)
- 내 우주선이 부딪혀 폭발할 때는 하늘색 계열 불꽃이 나옵니다.

### 5. 움직이는 별 배경
- 별 120개가 계속 아래로 흘러가서 우주를 날아가는 느낌을 줍니다.
- 별마다 크기, 속도, 밝기가 달라서 **큰 별은 빨리, 작은 별은 천천히** 움직입니다.
  → 가까운 별과 먼 별이 다른 속도로 지나가는 원근감 효과
- 화면 아래로 사라진 별은 다시 위에서 나타나 끝없이 이어집니다.

### 6. 효과음 4종 + 배경음악
- 발사음, 폭발음, 피격음, 재장전 완료음 → [소리는 어떻게 만들었나](#-소리는-어떻게-만들었나) 참고
- 배경음악은 `bgm_main.mp3`를 음량 50%로 반복 재생합니다.
- 홈 버튼을 눌러 앱을 내리면 음악과 게임이 멈추고, 다시 돌아오면 음악이 이어서 나옵니다.
- 앱을 완전히 끄면 음악과 효과음이 쓰던 메모리를 깔끔하게 정리합니다.

### 7. 전체 화면
- 위쪽 상태바와 아래쪽 내비게이션 바를 숨겨 게임 화면을 최대한 넓게 씁니다.
- 알림을 내렸다가 돌아와도 다시 전체 화면으로 돌아갑니다.
- 화면은 **세로로 고정**되어 있어서 폰을 돌려도 게임이 초기화되지 않습니다.

## 🖥 화면 구성

```
┌──────────────────────────────┐
│ Score: 120      AMMO  45/50  │ ← 왼쪽 위: 점수 / 오른쪽 위: 탄약
│                 ▓▓▓▓▓▓▓▓░    │
│      ·    ✦        ·         │
│    ◆          ⬢ 2/3          │ ← 적 (체력 막대 포함)
│  ·        ·            ✦     │
│            ●                 │ ← 총알
│      ·           ·           │
│             ▲                │ ← 내 우주선 (엔진 불꽃)
├──────────────────────────────┤
│   [ ◀ ]   [ FIRE ]   [ ▶ ]   │ ← 조작 버튼
└──────────────────────────────┘
```

**게임 오버 화면**
- 화면이 어둡게 덮이고 가운데에 빨간 `GAME OVER` 글자가 나옵니다.
- 그 아래에 "FIRE 버튼으로 재시작" 안내와 최종 점수가 표시됩니다.
- FIRE를 누르면 점수·탄약·적·총알이 모두 초기화되고 바로 다시 시작합니다.

## 🔊 소리는 어떻게 만들었나

효과음은 MP3나 WAV 파일을 쓰지 않고, **코드에서 소리의 파형을 숫자로 계산해서** 만들었습니다.
(`SoundSynthesizer` 클래스)

| 효과음 | 길이 | 만드는 방법 | 들리는 느낌 |
|--------|------|-------------|-------------|
| 발사음 | 0.15초 | 높은 음(1500Hz)에서 낮은 음(150Hz)으로 빠르게 떨어지는 소리 | "피융~" |
| 폭발음 | 0.4초 | 무작위 잡음(지지직 소리)을 처음엔 크게, 점점 작게 | "콰앙…" |
| 피격음 | 0.08초 | 낮은 음(220Hz)을 아주 짧게 | "툭" |
| 재장전 완료음 | 0.25초 | 660Hz 음 다음에 880Hz 음, 두 음이 각각 울리고 사라짐 | "띵-띵" |

- 소리는 앱이 시작될 때 **미리 한 번 만들어서 메모리에 올려두고**, 필요할 때 바로 재생합니다.
  그래서 총을 연달아 쏴도 소리가 늦게 나오지 않습니다.
- 소리 품질은 22,050Hz / 16비트 / 모노로 설정했습니다.

## 🎨 그래픽은 어떻게 그렸나

그림 파일 없이 안드로이드의 `Canvas`(그림판 같은 기능)로 도형과 색을 직접 그렸습니다.

**내 우주선**
- 파란색 몸체(뾰족한 삼각형), 양쪽 날개, 가운데 유리 조종석으로 구성
- 몸체는 왼쪽에서 오른쪽으로 색이 자연스럽게 변하고(그라데이션), 조종석은 빛이 반사되는 느낌
- 뒤쪽 엔진 불꽃 3개가 계속 커졌다 작아졌다 하며 깜빡임

**적 우주선**
- 마름모 / 육각형 / X자 모양을 각각 점을 이어서 그림
- 몸 주변에 은은하게 빛나는 효과(글로우), 가운데에 빛나는 핵

**총알**
- 하얀 동그라미 + 노랗게 퍼지는 빛 + 아래로 흐려지는 꼬리

**배경**
- 위쪽은 검은빛 남색, 아래로 갈수록 조금 밝은 남색으로 바뀌는 우주 배경

**그리는 순서** (나중에 그린 것이 위에 보임)
배경 → 별 → 점수 → 총알 → 적 → 폭발 조각 → 내 우주선 → 탄약 표시

## ⚙ 게임이 돌아가는 원리

게임은 아래 과정을 **1초에 약 60번** 반복합니다.

```
① 상태 업데이트 → ② 화면 그리기 → ③ 1.5초 지났으면 적 추가 → ④ 0.016초 쉬기 → ①로 돌아감
```

**① 상태 업데이트에서 하는 일 (순서대로)**
1. 재장전 중이면 3초가 지났는지 확인
2. 별을 아래로 이동
3. 폭발 조각을 이동시키고 수명이 다한 조각 삭제
4. 총알을 위로 이동(한 번에 32픽셀), 화면 위로 나간 총알 삭제
5. 적을 아래로 이동하고,
   - 총알과 가로·세로 50픽셀 안으로 가까워지면 **명중** 처리
   - 내 우주선과 가로·세로 70픽셀 안으로 가까워지면 **게임 오버**
   - 화면 아래로 나간 적은 삭제

**신경 쓴 부분**
- 게임 화면은 버튼과 따로 돌아가는 별도의 작업 흐름(스레드)에서 그려서, 버튼 입력과 화면 그리기가 서로 방해하지 않습니다.
- 총알·적·폭발 조각 목록은 화면을 그리는 도중에 바뀌어도 앱이 멈추지 않는 안전한 목록(`CopyOnWriteArrayList`)을 사용했습니다.
- 총알 1발이 적 여러 대를 동시에 맞히지 않도록, 한 번 명중하면 그 총알은 바로 사라집니다.
- 앱이 백그라운드로 가면 게임 반복을 멈추고, 화면이 다시 준비되면 이어서 돌립니다.

## 📁 프로젝트 구조

```
game/
├── app/
│   ├── build.gradle.kts              # 앱 빌드 설정 (SDK 버전 등)
│   └── src/main/
│       ├── AndroidManifest.xml       # 앱 기본 정보, 세로 화면 고정 설정
│       ├── java/com/example/game/
│       │   └── MainActivity.kt       # ★ 게임 코드 전체 (아래 표 참고)
│       └── res/
│           ├── layout/
│           │   └── activity_main.xml # 게임 화면 + 하단 버튼 3개 배치
│           ├── raw/
│           │   └── bgm_main.mp3      # 배경음악
│           └── values/               # 앱 이름, 색, 테마
├── gradle/                           # Gradle 버전·라이브러리 버전 관리
├── build.gradle.kts
└── settings.gradle.kts
```

**`MainActivity.kt` 안에 들어 있는 것들**

| 이름 | 역할 |
|------|------|
| `MainActivity` | 앱 시작점. 전체 화면 설정, 배경음악 재생, 버튼 연결, 앱을 내리거나 끌 때 정리 |
| `GameView` | 게임의 핵심. 반복 실행, 움직임 계산, 충돌 확인, 모든 그리기 |
| `SoundSynthesizer` | 효과음 4종을 코드로 만들고 재생 |
| `Player` | 내 우주선 위치 |
| `Enemy` | 적 우주선 (종류, 속도, 체력, 점수, 번쩍임 정도) |
| `Bullet` | 총알 위치 |
| `Star` | 배경 별 (위치, 크기, 속도, 밝기) |
| `Particle` | 폭발 조각 (위치, 움직이는 방향, 남은 수명, 색) |

## ▶ 실행 방법

1. 이 저장소를 내려받습니다.
   ```bash
   git clone <이 저장소 주소>
   ```
   또는 GitHub 페이지에서 **Code → Download ZIP** 으로 받아 압축을 풉니다.
2. Android Studio에서 **File → Open** 을 눌러 내려받은 폴더를 엽니다.
3. Gradle 동기화(Sync)가 끝날 때까지 기다립니다. (처음엔 몇 분 걸릴 수 있습니다)
4. 에뮬레이터를 켜거나 USB로 안드로이드 폰을 연결합니다.
5. 위쪽의 ▶ **Run** 버튼을 누르면 게임이 실행됩니다.

> 안드로이드 7.0 (API 24) 이상에서 실행됩니다.
